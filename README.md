# Java Programming Practice

A personal Java laboratory exploring language fundamentals through standalone exercises and IDE-based practice.

## Source map

- [`src/Main.java`](src/Main.java): a modern Java entry point with a loop.
- [`src/currenttime.java`](src/currenttime.java): time-related programming practice.
- [`src/exceptionhandling1.java`](src/exceptionhandling1.java): exception handling.
- [`src/if_else_codes_practice/`](src/if_else_codes_practice/): conditional-logic exercises.
- [`src/com/`](src/com/): additional Java source packages.

## Getting started

Open the repository in a Java-capable IDE, inspect a specific source file and run it individually. The `Main.java` example uses newer `void main()` and `IO.println()` syntax; use a recent JDK with the required language settings rather than assuming compatibility with Java 8 or 17.

## Scope and next steps

This is an educational source archive. A portable build file, automated test matrix and consistent documented JDK baseline have not been verified. Future improvements should group exercises into packages, add expected output, and test edge cases. IDE files are not a substitute for a reproducible command-line build.
